¿Quién distingue un gato de un perro?

Cuatro modelos intentaron clasificar 3.000 dibujos hechos a mano de Quick, Draw!. La red neuronal MLP acierta lo mismo que la SVM (84%) pero entrena 100 veces más rápido. El clustering no supervisado (HDBSCAN) queda por debajo del azar.

Una red neuronal es un modelo de machine learning que apila "neuronas" simples en capas y aprende a reconocer patrones a partir de datos para asignar entradas a outputs.

Las redes neuronales convolucionales son un tipo de red neuronal diseñada especialmente para analizar imágenes y otros datos con estructura espacial, como videos o mapas.
