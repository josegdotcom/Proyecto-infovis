\section{Contexto general}
% =========================================================

\subsection{Mensaje principal}

\textit{
Las inteligencias artificiales son percibidas como herramientas perfectas y universales, pero
esa percepci\'{o}n es errada.
Para demostrarlo, entrenamos dos redes neuronales ---una convolucional (CNN) y una de
propagaci\'{o}n densa (MLP)--- y las pusimos a prueba en dos tareas distintas: clasificar
dibujos de gatos y perros (datos de imagen) y reconocer actividades humanas a partir del
girosc\'{o}pio del tel\'{e}fono (datos tabulares).
La CNN destaca en im\'{a}genes; la MLP entrena m\'{a}s r\'{a}pido en ambas pruebas y
obtiene mejores resultados en actividades.
El objetivo es mostrar que cada modelo tiene sus fortalezas y limitaciones seg\'{u}n el
tipo de dato que procesa.
}

\subsection{Origen y procesamiento de los datos}

Los datos provienen de dos fuentes abiertas:
\textbf{Quick, Draw!} (Google) para los dibujos de gatos y perros, y
\textbf{Human Activity Recognition Using Smartphones} (UCI) para los registros de
acel\'{e}r\'{o}metro y girosc\'{o}pio.
Los dibujos se almacenaron en \texttt{gatos\_perros\_dataset.npz} y se procesaron mediante el
notebook \texttt{data/Prueba\_1.ipynb}; los datos de actividades en \texttt{har\_dataset.npz}
mediante \texttt{data/Prueba\_2.ipynb}.
Los resultados se exportaron a archivos CSV/NPZ en \texttt{data/resultados/} y luego a
\texttt{exploracion/datos.js} para ser consumidos por la visualizaci\'{o}n web.

suficientemente rica.

m\'{a}s una distinci\'{o}n entre tipos de datos, abriendo espacio para sonificaci\'{o}n y
narrativa visual.
El cambio fue impulsado por la necesidad de comunicar un mensaje concreto y verificable.

Se descart\'{o} el dataset de mesas operativas electorales y el concepto original basado en

\subsubsection{Qu\'{e} dijo del sonido}

En esta versión del proyecto se tenia un aplausómetro, sonando mas fuerte y con mas aplausos dependiendo del porcentaje de predicciones correctas. Menciono que le parecía entretenido, pero que no se entendía que era lo que se quería transmitir. 

\subsubsection{Heur\'{i}sticas que fallaron}

\begin{itemize}
  \item \textbf{La importancia del dato no est\'{a} clara:} el pensador no identific\'{o}
        r\'{a}pidamente qu\'{e} significaban los porcentajes del aplaus\'{o}metro ni por qu\'{e}
        importaban.
  \item \textbf{Falta contexto (fuente, pregunta):} con solo una prueba visible, el mensaje
        ``las redes no son universales'' no ten\'{i}a suficiente respaldo; faltaba la segunda
        prueba como contraste. 
  \item \textbf{La interacci\'{o}n no es descubrible:} la grilla de dibujos parec\'{i}a
        interactiva (el pensador intent\'{o} hacer click) pero no lo era, generando frustraci\'{o}n.
  \item \textbf{Un titulo inadecuado:} El objetivo desde el inicio era mostrar que las inteligencias artificiales no son tan universales, pero el titulo era "¿Quién distingue un gato de un perro?"
\end{itemize}

\subsubsection{Las tres respuestas de cierre}

\begin{itemize}
  \item \textbf{Atasco:} El pensador se atasc\'{o} m\'{a}s tiempo en la grilla de dibujos
        individuales (\textasciitilde{}45 segundos), intentando descifrar qu\'{e} significaban
        y c\'{o}mo interactuar con ellos, sin encontrar una relaci\'{o}n clara con el mensaje
        central.
  \item \textbf{Hip\'{o}tesis equivocada:} Supuso que el aplaus\'{o}metro era un elemento
        interactivo donde uno pod\'{i}a ``votar'' cu\'{a}l modelo era mejor, no un medidor de
        aciertos. Tambi\'{e}n dijo ``con solo una prueba, la CNN gana en todo'', cuando en
        realidad la MLP era m\'{a}s r\'{a}pida.
  \item \textbf{Cambio concreto:} Incorporar una segunda prueba con datos diferentes (tabulares o sonoras)
        para que el contraste entre modelos sea evidente, y remplazar el gráfico de puntos.
\end{itemize}

\subsubsection{Efecto en el proceso}

Lo aprendido se incorpor\'{o} en la transici\'{o}n V1 $\rightarrow$ V2:
\begin{itemize}
  \item Se agreg\'{o} el segundo dataset (Human Activity Recognition) para respaldar el
        mensaje con dos pruebas contrastantes.
  \item Se cre\'{o} la galer\'{i}a de exploraci\'{o}n con 19 alternativas de gr\'{a}ficos,
        buscando el tipo de visualizaci\'{o}n que mejor comunicara la comparaci\'{o}n ---lo que
        eventualmente llev\'{o} a elegir las barras comparativas en V3.
  \item El aplaus\'{o}metro qued\'{o} relegado, confirmando que el formato de medidor
        individual no era efectivo para comparar dos modelos.
\end{itemize}

\subsubsection{Efecto en el proceso}

Lo aprendido se incorpor\'{o} en la transici\'{o}n V3 $\rightarrow$ V4:
\begin{itemize}
  \item En el PR~\#4 (commit \texttt{4794886}) se ampli\'{o} la explicaci\'{o}n del
        experimento de actividades humanas, se agreg\'{o} el \'{i}cono
        \texttt{rotate\_phone.svg} para hacer m\'{a}s intuitivo el origen de los datos de
        sensores, y se revis\'{o} el texto contextual.
  \item En el PR~\#5 (commit \texttt{f595381}) se simplific\'{o} el CSS, se incorporaron
